About This Spotify Clone

This Spotify Clone project is fully created by me using HTML, CSS and JavaScript. The purpose of this project is to understand how audio control, playlists and UI synchronization works in real music streaming platforms. In this project I have implemented play, pause, next, previous, progress bar update and dynamic song name update features. The design is inspired by Spotify but coded completely from scratch by me. This project helped me a lot in improving my DOM manipulation, event handling and responsive layout concepts.

More features will be added soon like volume control, preferred playlist system, artist wise filtering and recent plays. This project is still under improvement and I enjoy working on it.
